# v1.2 交付说明 · 把「假彩票」改回真彩票

> 这版只干一件事：**删掉所有不像彩票的东西，然后把经济拉回会亏钱的真实结构。**

## 一、那个「提前开奖」，是我加错了

上一版柜台会让你在买之前看到 3 格结果。我当时的理由是「让挑票有决策」，但这个设计是错的：

- 买前就知道结果，等于把「刮」剧透完了，刮的过程变成走流程
- 玩家能算出这张票值不值，彩票的未知感直接消失
- 真实彩票店绝不会让你先看结果

**已经删干净了。** 柜台上不会再出现任何未购买票的结果。

## 二、换成真实彩票的「整本」

现在每款票只有**一本在售**，票是连号的，撕一张少一张：

```
A-0731 · 第 13/50 张
本内已出 3 笔 · 剩 37 张
```

| 规则 | 说明 |
|---|---|
| 一本 | 50 张，连号 |
| 在售 | 每款票一本，卖满 50 张才换新本 |
| 票面 | 印 `本号 · 第 n/50 张`，跟真票一样 |
| 头奖 | 每本固定 1 张，15 倍票面，位置随机 |
| 公示 | 只公布「本内已出几笔奖」，**不公布金额** |

为什么不公布金额：一旦公布总额，玩家就能反推「这本头奖还没出、只剩 5 张」，期望高达 3.4 倍，会被精确套利。只公布笔数就堵死了——15 倍头奖也只算一笔。

## 三、RTP 从 1.55 压到 0.78（金币终于会少）

上一版「金币花不完」的真正根因不是挂机，是**刮票本身在印钱**：原模型 RTP 高达 1.55–2.37，玩家每花 100 币平均拿回 155–237 币。拆掉挂机只是止血。

现在是真实奖级表结构：

| 项目 | 数值 |
|---|---|
| 普通张 RTP | 0.380 / 0.382 / 0.384（稳/平/冲） |
| 本内头奖 | 1/50 张 × 15 倍 → +0.30 |
| 跨本巨奖 | 1/500 张 × 50 倍 → +0.10 |
| **总 RTP** | **0.78**（三档差 0.45%） |
| 中奖率 | 33.6% / 30.6% / 25.5% |

刮 100 币平均拿回 78 币。**这次金币是真的会变少。**

## 四、其它改动

| 改动 | 内容 |
|---|---|
| 集点卡 | 买十送一。每买一张盖 1 点，满 10 点送 1 张赠票，下次买票自动抵扣。取代原来的「手气槽 / 运势券」 |

| 修了一个严重 bug | 买票扣两次钱（buyTicket 和 StartTicket 各扣一次），1000 张实盘发现，已修 |

## 五、验证记录

不是「应该没问题」，是真跑过：

| 项 | 方法 | 结果 |
|---|---|---|
| 返奖率 | 200 万张仿真 | 稳 0.7828 / 平 0.7797 / 冲 0.7839 |

这版用了引擎的 headless 运行时跑真实代码路径，不是纸上推演。
