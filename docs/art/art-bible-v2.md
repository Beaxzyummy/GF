## 1. 视觉身份

### 1.1 一句话定位

> **「一张能中奖的纸，被放进了一间打烊后仍亮着灯的彩票店。」**

不是赌场，是**印刷品**。不是霓虹堆砌，是**油墨与烫金**。
玩家第一眼应该觉得「这票是真的」，第二眼应该觉得「这店里还有好东西」。

### 1.2 三个关键词

| 关键词 | 含义 | 落到像素上 |
|---|---|---|
| **纸感（Paper）** | 票面是实物，有厚度、有纤维、有压痕 | 纸白底 + 1dp 内白边 + 底部 4dp 硬投影 + 极淡纤维噪点 |
| **金（Gold）** | 金是「值钱」的唯一隐喻，只给奖励与主行动 | 三停渐变 + 顶部 1dp 高光 + 底部 1dp 暗线，形成金属体积感 |
| **印刷（Print）** | 所有颜色来自油墨叠印，不是发光体 | 颜色饱和但发哑；边界锐利不发虚；不用大面积纯白纯黑 |

### 1.3 反面清单 —— 我们绝不做成什么样

| ❌ 绝不做 | 为什么 | 正确的做法 |
|---|---|---|
| 老虎机式的廉价霓虹堆砌（满屏紫粉流光） | 会被 TapTap 判为博彩向，且用户明确拒绝 | 霓虹只存在于 HOT 票这一小块，且用「深底 + 单色描边光晕」不用大面积渐变 |
| 纯黑背景 + 纯白文字 | 廉价、像未做设计的原型 | 底用 `ink-900 #120C09`（暖黑），字用 `text-100 #F5EFE3`（暖白） |
| 圆角一律 20dp 的「大软糖」 | 失去印刷品的硬朗 | 卡片 14 / 按钮 12-14 / 标签 11，**最大不超过 16**（弹窗除外） |
| 符号用 `✦ ✿ ◆ ● ★` 等装饰字符 | NotoSansSC 里没有，渲染成 □ | 只用汉字（福禄寿喜财）与 NanoVG 几何路径，见 §5 |
| 用 Emoji 当图标 | 平台字体不可控，样式跳脱 | 字标图标（汉字）+ 几何图标，见 §5.4 |
| 大面积纯色平涂无层次 | 平面化 = 草稿感 | 每个面至少「底色 + 1 层渐变 + 1 条高光/暗线」 |
| 中奖用爆炸式红光铺满全屏 | 赌博机观感 | 中奖用「金色光晕 + 彩纸 + 数字滚动」，画面仍保持克制 |
| 未中奖变灰、弹「很遗憾」 | GDD §11.5 明确禁止 | 保持原色，0.5s 后自动回选票页 |

## 2. 配色系统

> 所有色值同时给出 **hex** 与 **RGBA**（NanoVG 直接用 `nvgRGBA(r,g,b,a)`）。
> 命名规则：`层级-色相-明度`。Lua 侧统一挂在 `C` 表（见附录 A）。

### 2.1 品牌暗场（壳层 / 背景）

游戏厅是「打烊后仍亮着灯」的暖黑，不是纯黑。所有界面默认铺在这一层上。

| Token | Hex | RGBA | 用途 |
|---|---|---|---|
| `ink-900` | `#120C09` | `nvgRGBA(18,12,9,255)` | 全屏底色。**禁止用 #000000** |
| `ink-800` | `#1B120D` | `nvgRGBA(27,18,13,255)` | 底栏 / 顶栏 / 分区背板 |
| `ink-700` | `#241811` | `nvgRGBA(36,24,17,255)` | 卡片默认底色（当前原型已用，保留） |
| `ink-600` | `#2F2118` | `nvgRGBA(47,33,24,255)` | 卡片内凹区 / 进度条槽 / 输入位 |
| `line` | `#4A3626` | `nvgRGBA(74,54,38,255)` | 1dp 描边 / 分隔线 |
| `line-soft` | — | `nvgRGBA(255,255,255,20)` | 卡内浅分隔（比 line 更淡，用于卡片内部） |
| `vignette` | — | `nvgRGBA(0,0,0,120)` | 屏幕四角压暗（`nvgBoxGradient` 一圈） |

**壳层氛围光**（每个主界面顶部必须有，否则画面会「死」）：
```lua
-- 从屏幕顶部中央向下扩散的暖光，模拟店内射灯
local g = nvgRadialGradient(vg, W*0.5, -60, 40, H*0.55,
    nvgRGBA(212,175,55,26), nvgRGBA(212,175,55,0))
```

### 2.2 金 —— 品牌主强调

**金只给两件事：钱、主行动。** 其他地方出现金 = 违规。

| Token | Hex | RGBA | 用途 |
|---|---|---|---|
| `gold-100` | `#FFE9A8` | `nvgRGBA(255,233,168,255)` | 渐变高光停 / 光晕内芯 |
| `gold-300` | `#F6E29E` | `nvgRGBA(246,226,158,255)` | 主金文字（浅底上的「中奖」）/ 渐变上停 |
| `gold-500` | `#D4AF37` | `nvgRGBA(212,175,55,255)` | **品牌主金**。金额、金边框、图标 |
| `gold-700` | `#8A6A20` | `nvgRGBA(138,106,32,255)` | 渐变下停 / 金描边暗部 |
| `gold-900` | `#4A3610` | `nvgRGBA(74,54,16,255)` | 金底上的描边 / 阴影 |

**金渐变（烫金的标准配方，135° 自上而下）**：
```lua
local p = nvgLinearGradient(vg, x, y, x, y+h,
    nvgRGBA(246,226,158,255),   -- 顶：受光
    nvgRGBA(212,175,55,255))    -- 底：本色
```
再加一条下停到 `gold-700`：三停 `100% → 50% → 0%` 用时把 `nvgLinearGradient` 的两种颜色换成三停 `nvgLinearGradient` + 中间 `nvgStop` 不可用的情况下，用两次叠画（先画两停，再叠一层 `gold-700` alpha 0→90 的窄条在底部 30% 区域）。

### 2.7 三套票面皮肤（本项目的视觉分水岭）

> 三套皮肤必须**关闭颜色后仍能靠版式区分**。这是硬指标。

#### 对比总表

| 维度 | ① 福彩系（晨光 / 烫金 / 丝绒） | ② 体彩顶呱刮系（好运十倍）**主打** | ③ HOT 系（热力） |
|---|---|---|---|
| 定位 | 传统福彩，喜庆印刷 | 国标即开票，最「像真的」 | 美式赌城，夜场娱乐 |
| 纸底 | `paper-100 #F2E9D8` 米黄（旧纸） | `paper-50 #FBF7EF` 白（新纸） | `#0B0918` 深紫黑（塑料卡） |
| 主色 | `red-400 #E23A2E` | `red-500 #C8102E` | `neon-pink #FF2E88` |
| 辅色 | `gold-500 #D4AF37` | `green-500 #00A15C` | `neon-cyan #22E0FF` |
| 强调 | `gold-300` 烫金 | 白 + 红（高反差） | `neon-lime #B4FF3C` |
| 版式骨架 | **竖排匾额式**：顶部拱形红匾 + 双金线 + 圆角 12 | **表格栅格式**：顶部红条 + 绿细线 + 白网格，直角 4dp 圆角 | **斜切速度线**：左倾 8° 色块 + 斜纹底 |
| 装饰母题 | 铜钱纹 / 云纹（几何绘制） | 五角星几何 + 条形码 + 票号 | 速度斜线 / 光斑 |
| 字形处理 | 标题描边 + 投影，字距 +2dp | 数字极大（34dp），无装饰 | 标题倾斜 -6°，描边发光 |
| 涂层 | 哑光银 `#B9C0CB`，「刮」字水印 | 亮银 + 斜纹 + 红边「刮」 | 黑金涂层，刮开露荧光 |
| 圆角 | 12dp | 4dp（印刷票根更硬） | 10dp |
| 阴影 | `0 4 12 rgba(0,0,0,.45)` | `0 3 0 rgba(0,0,0,.35)`（硬投影，纸感） | `0 0 24 rgba(255,46,136,.35)`（发光） |
| 出现频率 | 中（解锁型） | **高（默认票，首页第一个）** | 低（高面额尝鲜） |

#### ① 福彩系详细规格

- 底色 `paper-100`，四周 1dp `#E23A2E` 描边，圆角 12dp
- 顶部拱形匾：用 `nvgArc` 画上半圆 + 矩形，填 `red-400`，内嵌 2dp 金线（`gold-500`）
- 票名：`gold-300` 24dp，描边 `gold-700` 1dp（画两次偏移 1px 的描边实现）
- 底部「中国福利彩票」小字 9dp，`ink-paper-2`
- 涂层：哑光银 `#B9C0CB` + 更密的横向拉丝（每 2dp 一条 alpha 8）

#### ③ HOT 系详细规格

- 底 `#0B0918`，左侧 8dp 倾斜红条（-8°）
- 票名 `HOT` 用 34dp 白字 + `neon-pink` 外发光（3 层叠画）
- 金额格 `$$` 必须用**汉字「金」**代替（NotoSansSC 没有 `$` 的双 S 造型需求，且 `$` 字形存在但双字母不如汉字统一）——**改用「金」字 + `neon-lime` 色**
- 涂层：`#2A2438` 黑金，刮开后格子底为 `#141024` + `neon-cyan` 描边
- 圆角 10dp，外发光 `0 0 24 rgba(255,46,136,.35)`

### 2.8 用色纪律（三条）

1. **一屏之内，高饱和色块面积 ≤ 25%。** 其余交给暗场与纸白呼吸。
2. **金只出现在「奖励」与「主按钮」**，且同一屏最多 1 个金色主按钮。
3. **红绿并置只出现在体彩皮肤**，且必须伴随汉字或形状冗余（见 §9.3）。

## 3. 字体与字阶

### 3.1 字体现状与应对

只有 `NotoSansSC.ttf` 一套，**单字重（Regular）**。字体本身覆盖 GB2312 常用字，足够。

**没有粗体怎么办？** 三种合法手段（按优先级）：

| 手段 | 实现 | 适用 |
|---|---|---|
| **伪粗体** | 同文本画两遍，第二遍偏移 `(0.6, 0)` dp，同色 | 标题、票名、金额（≤ 24dp 效果好，>32dp 会糊） |
| **描边加粗** | 先 `nvgStrokeColor` + `nvgStrokeWidth(1.2)` 描同字形，再 fill | 大标题（招牌字），可配合描边色做金边 |
| **字号 + 色彩对比** | 靠 24dp vs 13dp 的落差建立层级 | 正文层级（最安全，默认用这个） |

> ⚠️ **禁用**：`nvgText` 的斜体/合成斜体、伪粗体偏移 > 1dp（会重影）。

### 3.2 字阶表（单位 dp，物理 = ×3）

| Token | 字号 | 行高 | 用途 | 字距 | 备注 |
|---|---|---|---|---|---|
| `D0` | 40 | 48 | 大奖金额（结算页） | 0 | 伪粗体 + 金渐变 |
| `D1` | 32 | 40 | 页面核心数字（转盘指针上方奖励） | 0 | |
| `H1` | 24 | 32 | 页面标题 / 票名 | +1 | |
| `H2` | 20 | 28 | 卡片标题 / 弹窗标题 | +0.5 | 伪粗体 |
| `H3` | 17 | 24 | 列表主文字 / 按钮文字 | 0 | |
| `B1` | 15 | 22 | 正文 | 0 | 行高 1.47 |
| `B2` | 13 | 20 | 次要正文 / 说明 | 0 | **中文正文下限** |
| `C1` | 12 | 16 | 标签 / 单位 / 角标 | +0.5 | |
| `C2` | 10 | 14 | 极小标签（**仅非信息性**：票号角标、装饰） | +1 | 禁止承载关键信息 |

### 3.3 特殊排版规则（中文注意点）

1. **金额数字**：`148,200` 千分位逗号；不做等宽处理（NotoSansSC 数字近似等宽，够用）；金额与单位之间**不留空格**（`500币` 不是 `500 币`），但单位字号降一档并降色。
2. **中文标点**：只用全角 `，。：「」`；**禁止**在汉字之间夹半角逗号；省略号用 `……`（6 点）不用 `...`。
3. **数字与汉字混排**：`Lv.3`、`×2`、`+5票` 一律半角，前后不加空格。
4. **标题不做两端对齐**，短标题居左；居中的只有弹窗标题与结算金额。
5. **行首禁则**：`，。：」` 不出现在行首。NanoVG 无自动避头尾，采用「手动断行表」：长文案在数据层就按 ≤14 字切句，避免运行期断行。
6. **最大行宽**：单行 ≤ 18 个汉字（360dp 屏），超过必须断行。
7. **大标题字距**：`H1` 及以上加 `+1~+2` dp 字距。中文加字距会显得「郑重」，这正是彩票该有的调性；正文**绝不能**加字距（会散架）。

### 3.4 文字颜色配对表（避免用错）

| 背景 | 主文字 | 次文字 | 禁用 |
|---|---|---|---|
| `ink-900/800/700` | `text-100` | `text-300` | `text-500` |
| 金渐变按钮 | `ink-paper #2B2118` | — | 白色（对比不足） |

## 4. 材质语言

> 本章是「不做成草稿」的核心。**每一个面都必须至少两层**：底色 + 一层质感 + 一条高光或暗线。
> 所有手法只用 NanoVG 已有的：`nvgLinearGradient` / `nvgRadialGradient` / `nvgBoxGradient` / 路径 / 半透明叠画。

### 4.1 烫金（Hot Foil）—— 用于金色按钮、金额、金框

四层叠加，顺序不可乱：

```
① 底色：nvgLinearGradient(垂直) gold-300 → gold-500 → gold-700
② 顶部内高光：矩形 (x+2, y+1, w-4, 1.5)  fill rgba(255,255,255,150)
③ 底部内暗线：矩形 (x+2, y+h-2, w-4, 1.5) fill rgba(74,54,16,120)
④ 斜向高光带（可选，仅大块金）：-20° 平行四边形，宽 w*0.18，
   fill nvgLinearGradient(横) rgba(255,255,255,0) → rgba(255,255,255,70) → rgba(255,255,255,0)
```

```lua
local function drawGold(nvg, x, y, w, h, r)
    local p = nvgLinearGradient(nvg, x, y, x, y + h,
        nvgRGBA(246,226,158,255), nvgRGBA(212,175,55,255))
    nvgBeginPath(nvg); nvgRoundedRect(nvg, x, y, w, h, r)
    nvgFillPaint(nvg, p); nvgFill(nvg)
    -- 下停暗部
    local p2 = nvgLinearGradient(nvg, x, y + h*0.55, x, y + h,
        nvgRGBA(138,106,32,0), nvgRGBA(138,106,32,150))
    nvgBeginPath(nvg); nvgRoundedRect(nvg, x, y, w, h, r)
    nvgFillPaint(nvg, p2); nvgFill(nvg)
    -- 顶部高光
    nvgBeginPath(nvg); nvgRoundedRect(nvg, x+2, y+1, w-4, 1.5, 0.75)
    nvgFillColor(nvg, nvgRGBA(255,255,255,150)); nvgFill(nvg)
end
```

### 4.2 镭射（Holographic）—— 仅用于「特等奖」「UR」这类稀缺时刻

三层不同角度的线性渐变叠加，每层 alpha 30-50，模拟薄膜干涉：

| 层 | 角度 | 颜色 |
|---|---|---|
| L1 | 0°（横） | `rgba(34,224,255,50)` → 透明 → `rgba(255,46,136,50)` |
| L2 | 60° | `rgba(180,255,60,45)` → 透明 → `rgba(139,92,246,45)` |
| L3 | 120° | `rgba(255,255,255,60)` 细条 × 4（每 12dp 一条，宽 2dp） |

> 只在**大奖结算**与**抽卡 UR** 两处使用，一屏面积 ≤ 30%。用多了就变成「廉价镭射纸」。

### 4.3 纸张纤维（Paper Grain）—— 每个票面必备

预生成一次（存表，不每帧随机，否则会闪）：

```lua
-- 初始化时生成，之后每帧按固定坐标重绘
local fibers = {}
for i = 1, 140 do
    fibers[i] = {
        x = math.random() * 340, y = math.random() * 520,
        len = 3 + math.random() * 9,
        a   = 5 + math.random() * 7,      -- alpha 5~12
        ang = math.random() * math.pi,
    }
end
```
- 纤维：1dp 长线，`rgba(201,185,155, a)`，随机角度
- 边缘压暗：`nvgBoxGradient(x, y, w, h, r, 10, rgba(0,0,0,0), rgba(0,0,0,22))` 画在纸面上
- **纸的厚度**：在票卡底部画 `0 3 0 rgba(0,0,0,88)` 的硬投影 + 顶边 1dp `rgba(255,255,255,160)` 内高光

### 4.4 金属拉丝（Brushed Metal）—— 涂层刮开前的银层

- 底：`nvgLinearGradient(135°)` `#DCE1E8 → #B9C0CB → #8A929F`
- 拉丝：每 2dp 画一条 1dp 横线，alpha 在 6/10 之间交替（用 `i % 2` 决定）
- 斜纹：每 8dp 一条 45° 线，`rgba(255,255,255,36)`，宽 3dp
- 中心高光：`nvgRadialGradient` 从格子中心，内径 0 alpha 60 → 外径 `cellH*0.8` alpha 0
- 「刮」字：`#6E7683`，字号 `cellH*0.32`，alpha 140，居中
- 边缘：1dp `rgba(0,0,0,46)` 内描边

### 4.5 霓虹（Neon）—— 仅 HOT 皮肤与「电量」图标

三遍叠画，从外到内：

```
① 外晕：同形状放大 6dp，fill rgba(color, 30)
② 中晕：同形状放大 2dp，fill rgba(color, 70)
③ 芯体：原形状，fill 提亮色（如 pink → #FF8FC0）
④ 描边：1.5dp 原色
```

> 只用 2 个颜色（pink + cyan），**绝不三色以上**。这是「不像赌博机」的关键。

### 4.6 光晕与压暗（全屏通用）

- **顶光**：`nvgRadialGradient` 从 `(W/2, -60)`，半径 `H*0.55`，`rgba(212,175,55,26) → 0`
- **四角压暗**：`nvgBoxGradient(0,0,W,H, 0, 80, rgba(0,0,0,0), rgba(0,0,0,110))`
- **中奖闪光**：全屏 `rgba(255,255,240, a)`，a 从 200 → 0，400ms

### 5.2 可用汉字符号集（已逐个确认在 NotoSansSC 中）

**主符号（刮刮乐 9 格，5 种）**：

| 符号 | 色值 | 语义 | 几何辅助 |

| 福 | `#E85C4E` `nvgRGBA(232,92,78,255)` | 基础 | 无 |

┌────────┐   40×40 dp 圆角方

**必须验证的字符清单**（按风险从高到低）：

|---|---|---|---|---|

**面额数字的自适应规则（v2.0 数值放大后必须遵守）**

面额从两位数放大到五位数（`100` → `100,000`），右侧面额区宽度有限（固定 **104dp**，含打孔线间距）。规则如下：

| 面额位数 | 字号 | 示例 | 说明 |
|---|---|---|---|
| 1–3 位 | 17dp | `200币` | 默认 |
| 4 位（含千分位逗号） | 15dp | `4,000币` | 字号降一档，其余不变 |
| 5–6 位 | 15dp + 单位降为 9dp | `100,000币` | 数字必须横向压缩，**禁止换行** |
| 任何情况下 | — | — | 面额列**永不换行**（`white-space: nowrap` / NanoVG 单行绘制），超宽时先降字号，最低 13dp |

> 若五位数仍溢出（如同时显示「剩 N 张」），**优先压缩数字字号，而不是缩写**。
> 禁止用 `10万` 这类汉字缩写替代面额——票面金额是玩家做决策的依据，必须给准确数字。

高 40，r 20，fill `rgba(18,12,9,235)`，1dp `rgba(212,175,55,90)`，文字 13dp `text-100`，距底 96dp，进 200ms 上滑 12dp + 淡入，停留 1.2s，出 200ms 淡出。

|---|---|---|

**已刮状态（内容）**：

## 7. 动效原则

### 7.1 三条原则

1. **动作要「有重量」**：所有出现用 `easeOutBack` 轻微过冲（1.05-1.06），消失用 `easeIn` 直接走，不回弹。
2. **中奖要「有停顿」**：揭示前留 250ms 空白，让玩家意识到「发生了」。
3. **克制优先**：一屏内同时运动的元素 ≤ 3 组。粒子只在中奖/大奖时出现。

### 7.2 缓动曲线表（Lua 与 CSS 通用）

| 名称 | cubic-bezier | 用在哪 |
|---|---|---|
| `easeOutCubic` | `0.215, 0.61, 0.355, 1` | 通用出场、金额滚动 |
| `easeOutQuart` | `0.165, 0.84, 0.44, 1` | 转盘 |
| `easeOutBack` | `0.34, 1.56, 0.64, 1` | 弹窗、卡片入场 |
| `easeInOutQuad` | `0.455, 0.03, 0.515, 0.955` | 页面切换 |
| `easeInQuad` | `0.55, 0.085, 0.68, 0.53` | 消失 |

### 7.3 时长表

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 按钮按下 | 90ms | easeOut | `scale 0.96` + 下移 1dp |
| 按钮抬起 | 160ms | easeOutBack | 回弹到 1.0 |
| 页面切换 | 250ms | easeInOutQuad | 新页从右滑入 24dp + 淡入 |
| 卡片入场（列表） | 280ms | easeOutBack | 依次错开 40ms，最多错开 4 张 |
| 弹窗出现 | 200ms | easeOutBack | scale 0.92 → 1.0 |
| 弹窗关闭 | 150ms | easeInQuad | scale 1.0 → 0.96 + 淡出 |
| **刮除单格** | 120ms | easeOutCubic | 涂层 `scale 1 → 0.92` 同时 alpha 1 → 0，格内容从 0.94 弹到 1.0 |
| 刮除进度条 | 200ms | easeOut | 无回弹 |
| 自动全揭 | 350ms | easeOutCubic | 每格错开 40ms |
| **开奖前停顿** | **250ms** | — | 什么都不发生，只有极轻的屏息感 |
| 光晕爆发 | 500ms | easeOutCubic | 径向光晕半径 0 → 260dp，alpha 180 → 0 |
| 金额滚动 | 900ms | easeOutCubic | 每帧 `cur += (target-cur) * 0.15`，末尾吸附 |
| 彩纸 | 1200ms | 物理 | 初速 -320~-520 dp/s 向上，重力 900 dp/s²，旋转 ±360°/s |
| 屏幕闪光 | 400ms | easeOut | 全屏白 alpha 200 → 0 |
| **转盘** | **3200ms** | easeOutQuart | 4 圈 + 落位角；最后 400ms 加 ±1.5° 阻尼抖动 |
| 转盘落位高亮 | 400ms | easeOutBack | 中奖扇区亮度提升 + 白色描边 |
| 批量结算（10 张） | 1200ms | easeOut | 每张错开 90ms |
| Toast 进/出 | 200ms | easeOut / easeIn | 上滑 12dp |
| 广告按钮金边呼吸 | 1200ms × 2 | easeInOutQuad | 循环，周期 2.4s |

### 7.4 粒子规范

| 参数 | 值 |
|---|---|
| 刮除碎屑 | 每格 6 个，直径 2-3dp，色 `#B9C0CB` → 透明，寿命 0.5s，初速 60-140 dp/s 随机角，重力 400 |
| 中奖彩纸 | 24 片，4×8dp，色取 `gold-500 / red-500 / green-300 / white`，寿命 1.2s |
| 大奖爆发 | 48 片 + 8 道金色光条（旋转） |
| 上限 | 同屏粒子 ≤ 64，超出丢弃最旧的（性能兜底） |

- 底部手势条：24dp 内不放置可点击元素
- 全面屏更高的设备：多出的高度全部给「内容区」，卡片不拉伸
- 超宽屏（平板）：内容区最大宽度 **420dp** 居中，两侧背景延展

## 9. 可访问性

### 9.1 分级：**Standard**（本项目目标）

| 等级 | 要求 | 本项目 |
|---|---|---|
| Basic | 可读字号、可点击尺寸 | ✅ 已满足 |
| **Standard** | + 对比度达标、色盲冗余、动效开关 | ✅ **目标** |
| Comprehensive | + 完整键鼠/外接手柄、屏幕阅读 | ❌ 不做（单机竖屏，投入产出不划算） |
| Exemplary | + 全语音导航 | ❌ 不做 |

### 9.2 特性矩阵

| 特性 | 状态 | 实现规格 |
|---|---|---|
| 对比度（正文） | ✅ 必须 | 正文 ≥ **4.5:1**，大字（≥24dp）≥ **3:1** |
| 对比度（非文本） | ✅ 必须 | 按钮边框、图标、进度条 ≥ **3:1** |
| 字号下限 | ✅ 必须 | 中文正文 **≥13dp**（物理 39px）；关键信息 ≥15dp；10dp 仅限票号等装饰 |
| 触控目标 | ✅ 必须 | **≥44×44dp**，间距 ≥8dp |
| 色盲冗余 | ✅ 必须 | 见 §9.3 |
| 动效减弱 | ✅ 必须 | 设置内置「减少动效」开关：转盘 400ms 转 1 圈直接出结果；彩纸数量 24→6；屏幕闪光取消；页面切换改为直接切 |
| 文字缩放 | ⚠️ 部分 | 提供「大字模式」：全局字阶 ×1.15（`D0` 除外），卡片高度自适应 |
| 声音替代表达 | ✅ 必须 | 所有音效反馈必须有视觉等价物（中奖有金色光晕与金额跳动，不依赖音效） |
| 单手可达 | ✅ 必须 | 主行动按钮全部位于屏幕下 1/3 |
| 屏幕阅读 | ❌ 不做 | 平台无稳定读屏支持 |

### 9.3 色盲友好（含实测对比度）

**关键测量**（WCAG 相对亮度）：
- `red-500 #C8102E` 亮度 L ≈ **0.128**
- `green-500 #00A15C` 亮度 L ≈ **0.262**
- `green-700 #00713F` 亮度 L ≈ **0.122**

**结论与强制规则**：

1. **`red-500` 与 `green-700` 亮度几乎相同（0.128 vs 0.122）**，红绿色盲下完全无法区分。
   → **规则：红与绿永不单独承载「成功/失败」「中/未中」的语义。** 两者并置时只做装饰（体彩票头的红条 + 绿线），语义必须由**汉字**承担（「中」字圆章、「未」字）。
2. `green-500` 在 `paper-50` 上对比度仅 **3.1:1**，**禁止**用作正文文字色；纸面上的绿色文字一律用 `green-700`（5.7:1）。
3. `red-500` 在 `paper-50` 上 **5.5:1**，可作正文。
4. `gold-500` 在 `ink-900` 上 **9.1:1**，安全。
5. `text-500 #8A7C68` 在 `ink-700` 上仅 **3.9:1** → 不达正文标准，**只允许 ≥14dp 且非关键**。
6. 中奖状态除了颜色，必须同时有：**加粗描边（2dp 红框）** + **「中」字圆章** + **底色变浅（#FFF6D8）** 三重冗余。

### 9.4 深色模式的说明

本项目**只有一套配色**（暖黑暗场），不提供浅色模式。
理由：票面本身是「亮面」，若再提供浅色壳层，票面就会失去「实物纸」的对比，反而更难读。

### 9.5 自检清单（每次改 UI 后跑一遍）

- [ ] 所有文字色在对应底色上对比度 ≥ 4.5:1（或字号 ≥24dp 时 ≥3:1）
- [ ] 没有 12dp 以下的正文
- [ ] 所有可点元素 ≥44×44
- [ ] 中奖/未中奖状态在灰度截图下仍可区分
- [ ] 没有任何 `✦ ✿ ◆ ● ★` 等非 CJK 字符
- [ ] 没有使用 `#000000` / `#FFFFFF` 纯色
- [ ] 每个面至少有「底色 + 一层质感」
- [ ] 一屏内只有 1 个金色主按钮
